# Автоматизация Upwork

Единственная команда пользователя в Antigravity 2.0 UI: `/upwork-init <URL>`.
Все общие правила объявлены `always_on`; нативные `.agents/{rules,skills,agents}.json` подключают один источник, правила проекта зарегистрированы отдельно.
Локальные параметры — `.agents/rules/90-project.md`, источники контекста — `.agents/context.json`, среда и точные модели — `runtime.json`.
Симлинки, hardlinks и копирование общих модулей для новых проектов не используются.

Проект: `.md`, ручная `KB/Project.md`, агентская `ꘖ/KB`, служебная `ꘖ/data`, журнал `ꙮ/1 - Анализ/{req,res}`, контекст `ꙮ/0/Context.md`.
Первоначальный ручной документ сразу полностью копируется в агентскую KB; повторная инициализация сохраняет существующие файлы.
F — наблюдение/слова источника, H — гипотеза, M — способ решения; связи и доказательства определены в [правилах KB](rules/06-knowledge-base.md).

Делегирование должно быть видно в UI: сложные задачи — субагентам A.A (`self`), простые — A.F (`af-worker`). Точные версии/High требуют проверки метаданных; tier сам по себе их не гарантирует.
`doctor` проверяет файлы и сообщает байты; фактическую загрузку правил и [бюджет платформы](https://antigravity.google/docs/rules/#size-limits-and-token-budgets) проверяют в сессии UI.
