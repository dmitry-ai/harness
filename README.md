# Единый источник правил и инструментов (`.agents`)

Эта папка (`C:\work\upwork\code\AI\primary\result\.agents`) является единым источником истины (Single Source of Truth) для общих правил, детерминированных Python-утилит, тестов, навыков (`skills`) и субагентов (`agents`).
Каждое предложение в правилах и документации начинается с новой строки (`DOC-6`).

## Архитектура подключения к проектам Upwork

Вместо полного копирования файлов в каждый проект используется гибридная схема с симлинками и манифестами Antigravity 2.0 (`link_project_agents` в `upwork_project.py`):
- Папки `.agents/scripts`, `.agents/tests`, `.agents/skills` и `.agents/agents` в проекте ссылаются на `C:\work\upwork\code\AI\primary\result\.agents\...`.
- Папка `.agents/rules/` в проекте создаётся как реальная директория: общие модули `00-scope.md` .. `09-initial-analysis.md` подключаются через симлинки на `C:\work\upwork\code\AI\primary\result\.agents\rules\`, а специфичные для конкретного проекта правила хранятся в локальном файле `.agents/rules/90-project.md`.
- Дополнительно создаются манифесты `.agents/rules.json` и `.agents/skills.json`, а также локальная конфигурация `.agents/context.json` (`"output": "ꙮ/0/Context.md"`).
- Благодаря этому любые изменения в универсальных правилах `00-`..`09-` или скриптах в `primary/result/.agents` мгновенно применяются ко всем проектам, а локальные правила `90-project.md` остаются изолированными внутри своего проекта.

## Структура директории проекта Upwork

Каждый проект создаётся по пути `C:\work\upwork\code\proposals\daily\YYYY\MM\DD\<N> - <domain_or_topic>` и автоматически регистрируется в плагине `Folders` Antigravity (`<domain_or_topic> - U.P.YYYY.MM.DD` в `Upwork -> Proposals -> YYYY -> MM -> DD`):
- `.md` — корневой файл с заголовком проекта и ссылкой `https://upwork.com/jobs/~...`.
- `KB/` — ручная база знаний пользователя (`KB/Project.md` автоматически заполняется только один раз на этапе первичного анализа и далее агентом не изменяется согласно `KB-1`).
- `ꘖ/KB/` — управляемая агентом база знаний (`Client.md`, `Website.md`, `Projects.md`, `Glossary.md`, `.md`), куда сразу портируются данные из `KB/Project.md` и вносятся все последующие уточнения.
- `ꘖ/data/` — папка для служебных и временных файлов агента (`ꘖ/data/.journal/`, `ꘖ/data/.draft-snapshots/`, `ꘖ/data/context.lock`; временные файлы удаляются сразу после использования).
- `ꙮ/0/Context.md` — автоматически собираемый полный контекст проекта (включая `KB`, `ꘖ/KB` и журналы `ꙮ/1 - Анализ`).
- `ꙮ/1 - Анализ/req/` и `res/` — журнал запросов и ответов анализа.

## Навыки (слэш-команды) и субагенты

- `/analyze-project <url>` (и алиас `/upwork-init <url>`) — слэш-команды из `.agents/skills/`, запускающие детерминированную выгрузку вакансии через CDP, создание структуры проекта и полный первичный анализ (определение сайта, анализ беспокойств клиента §26.1 и заблуждений клиента §26.2 по правилам гипотез §27 / `DOC-8`).
- `af-worker` (`.agents/agents/af-worker.md`, `model: flash`) — вспомогательный субагент `A.F` на модели `Gemini 3.8 Flash` (`High`), которому главный агент `A.A` (`Gemini 4 Argon` `High`) делегирует рутинные и проверочные подзадачи.
- Подробное описание всех CLI-команд приведено в [инструкции](scripts/README-agent-tools.md).
