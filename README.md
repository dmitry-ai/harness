# Шаблон проекта

Скопируйте папку `.agents/` целиком в корень нового проекта.
Внутри находятся правила, инструменты, тесты, инструкции и пример конфигурации.
Дополнительные папки `scripts/` и `tests/` в корне проекта не нужны.
Все команды в инструкциях выполняются из корня проекта.
Девять общих модулей работают без привязки к wayse.pt, контракту, аккаунтам или конкретному компьютеру.
Каждое предложение в правилах начинается с новой строки.

Общий код расположен в `.agents/scripts/agent_tools/`, тесты — в `.agents/tests/`.
Установка зависимостей, команды, восстановление журнала и ограничения проверок описаны в [инструкции](scripts/README-agent-tools.md).
Пример конфигурации контекста нужно заполнить реальными путями нового проекта и сохранить как `.agents/context.json`.
Журнал и валидаторы не требуют этой конфигурации.
Если нужны только правила, можно отдельно скопировать `.agents/rules/`.

Правила объясняют агенту, когда и как запускать команды.
Python не исполняется автоматически при чтении Markdown.
Git-хуки и фоновая автоматизация не устанавливаются.

Проектные отличия добавляйте небольшим модулем `90-…`.
Факты о клиенте храните в KB, пути источников контекста — в конфигурации.
Проектные модули wayse.pt, профили Chrome, Gemini и разовые исследования в шаблон не включены.

Все модули правил имеют `trigger: always_on`.
Antigravity поддерживает `.agents/rules/*.md` непосредственно.
Наличие этого поля не доказывает фактическую загрузку полного текста при превышении бюджета среды.
Для других агентов используйте штатный способ подключения инструкций.
[Документация Antigravity](https://antigravity.google/docs/rules#directory-scoped-rules).

История анализа и резервные копии находятся в `AI/ꙮ/2026/10/11/audit/` исходного рабочего каталога.
Для использования шаблона они не нужны.
