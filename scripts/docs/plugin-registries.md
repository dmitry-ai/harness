`scripts/agent_tools/gates/` discovers `PreToolUse` gate plugins automatically in ascending `(PRIORITY, NAME)` order via `discover_pre_tool_gates()` and `run_pre_tool_gates()`, keeping `RULES-BUDGET-GATE` (`10`, enforcing local `.agents/rules/` and shared `rules/*.md` budgets plus HTML-comment stripping), `EXEC-5-ISSUE-FIRST-GATE` (`100`) strictly before `ARCH-AUDIT-GATE` (`105`, zero-subprocess Protection Proxy enforcing `ARCH-1`/`ARCH-2` and module-hash cached `arch-auditor` receipts) and `EXEC-2-TDD-GATE` (`110`), followed by `CODE-SIZE-RATCHET-GATE` (`120`), `CODE-STYLE-GATE` (`125`, AST/tokenize `CODE-1` Python style ratchet), and `XREF-GATE` (`127`).

`scripts/agent_tools/cli_registry.py` and `scripts/agent_tools/cli_domains.py` register CLI subcommands declaratively; run `harness.py cli-docs` to render the current command index directly from the registry.
